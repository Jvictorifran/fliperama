# Gabinete de fliperama 3D

Modelo 3D interativo do gabinete de fliperama (IHC · Atividade 1, REV. C).
Página estática em um arquivo só: `site/index.html`.

## Rodar

```bash
docker compose up -d
```

Abre em `http://IP_DA_VPS:8080`.

## Atualizar

```bash
git pull
```

O container lê a pasta `site/` direto, não precisa reiniciar.
